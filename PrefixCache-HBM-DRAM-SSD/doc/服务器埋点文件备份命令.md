# 服务器埋点文件备份与替换命令

将三个修改后的 Python 文件上传到服务器 `/root/vllm-trace/` 后，执行以下命令。命令会先将服务器原文件备份到 `/root/vllm-trace/backup/` 下的时间戳目录，再替换为埋点版本。

```bash
set -euo pipefail

BACKUP_DIR=/root/vllm-trace/backup/$(date +%Y%m%d-%H%M%S)
mkdir -p "$BACKUP_DIR"

cp -p /vllm-workspace/vllm/vllm/v1/core/kv_cache_manager.py \
  "$BACKUP_DIR/kv_cache_manager.py"

cp -p /vllm-workspace/vllm-ascend/vllm_ascend/distributed/kv_transfer/kv_pool/ascend_store/pool_scheduler.py \
  "$BACKUP_DIR/pool_scheduler.py"

cp -p /vllm-workspace/vllm-ascend/vllm_ascend/distributed/kv_transfer/kv_pool/ascend_store/kv_transfer.py \
  "$BACKUP_DIR/kv_transfer.py"

cp -f /root/vllm-trace/kv_cache_manager.py \
  /vllm-workspace/vllm/vllm/v1/core/kv_cache_manager.py

cp -f /root/vllm-trace/pool_scheduler.py \
  /vllm-workspace/vllm-ascend/vllm_ascend/distributed/kv_transfer/kv_pool/ascend_store/pool_scheduler.py

cp -f /root/vllm-trace/kv_transfer.py \
  /vllm-workspace/vllm-ascend/vllm_ascend/distributed/kv_transfer/kv_pool/ascend_store/kv_transfer.py

echo "备份并替换完成：$BACKUP_DIR"
```

替换完成后，重新执行 `StartUp.sh` 重启 vLLM，再使用最新的 `Run-all` 内容执行压测。
